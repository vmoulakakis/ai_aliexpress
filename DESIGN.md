# FOUND. — Spatial discovery design contract
Version2026-11-22 / AXI-HORIZONX-20261122. User-directed redesign supersedes cream/serif art direction.

## Product and journey
Greek-first problem-led commerce research: need → candidate mechanism → actual source evidence → considered affiliate handoff. Real source data and explicit unknowns. Classification is a hypothesis; no rating, savings, demand, scarcity or shipping invented.

## Art direction
Original spatial product gallery informed by HorizonX.so interaction principles. Paper-white/ice canvas, precise black sans hierarchy, warm orange discovery accent, charcoal need-exploration scene, generous image stages and a compact pill navigation. Signature: product focus rail transforms neighboring images in perspective as selection changes; an actual job and source price accompany selected item. No copied templates/assets, no decorative orb, fake worker animation or generic dashboard card wall.
Tokens: canvas#f7f8fa, surface#ffffff, ink#15171b, muted#626872, line#e2e5e9, accent#ef6338, dark#14171d. Orange is decorative or has dark text; body/action text must meet contrast. Greek-capable system UI sans, strong weight/letter-spacing used with Greek line-height>=1.08. Spacing8px rhythm, container1280px, card radius20px, image ratio4:3. Shared components govern home/map/catalog/detail.

## Interaction states
- Gallery: manual previous/next, native button pagination, keyboard arrows and touch swipe, active item details. No autoplay or fake 360 spin. Reduced motion removes transform transitions but preserves controls/content.
- Need explorer: real counts from full AXI summary; button selection/search by existing labels; actual bounded product query through read-only proxy, explicit loading/error/retry/empty. Abort stale responses, cache per selected group. Never label local text search as new AI reasoning.
- Catalog: server pagination, active problem filter, sample/card count separate from full summary. EUR50+ listing prices only. Images have source-identity disclaimer, affiliate actions only on details.
- Detail: correct AXI ID, listing EUR, source timestamp/document, model interpretation pending review, original-source link and unchanged sponsored affiliate CTA. Unknowns use progressive disclosure without hiding material price/shipping limits.
- Source unavailable: no fabricated zero metrics, blank products or pretend recommendations. Real retry/reload links.
- Keyboard: skip link, visible focus, meaningful nav/current, semantic controls,44px+ touch targets, no traps.
- Responsive:320/360/390 mobile show central focus + neighboring cue; no page overflow. Need selector becomes horizontal native scroll/list; desktop splits exploration and results. Tablet has intentional2-column cards. Normal document scrolling retained.
- Motion:120–220ms feedback,400ms product-focus continuity, single entry composition<=600ms. CSS transforms/opacity only. prefers-reduced-motion removes entry/perspective motion, scroll smooth and transitions. No WebGL, shader, audio, added motion runtime or hidden content pending animation.

## Boundaries
No schema, Vault, paid inference or legacy agent rewrite. Existing /discover and legacy Europe routes retain behavior, with honest existing limitations. New read proxy permits only fixed endpoint and validated catalog params. No production promotion without review. Browser render, not compilation, decides visual acceptance.
