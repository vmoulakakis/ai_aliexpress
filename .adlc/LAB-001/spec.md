# LAB-001 — specification

Server-rendered Next.js route mounts a client configurator. `web/lib/lab/catalog.ts` is a bounded editorial research snapshot; `planner.ts` owns validation, totals, keyword matching, export and saved-state validation. A unique keyword match selects a preset; ambiguity returns no-match, not an invented recommendation. No LLM is connected; the product explicitly explains this.

The source snapshot is separate from the frozen demand pipeline and is not promoted into production product intelligence. Presets are research starting points, not verified assembled systems. Every cost is an editable planning allowance, not a verified merchant quote. No current stock, commissioning or performance guarantee is implied.

No backend APIs or external data stores are required. Browser localStorage is written only by the explicit save action. Goal and cost data never enter URLs. Download sanitizes CSV formula-leading cells. React escapes input. External URLs are editorial constants and use noopener/noreferrer. Sharing copies preset/tier only. Network/model cost: zero beyond existing site hosting. Rollback: omit this branch/preview; the default branch is not changed.
